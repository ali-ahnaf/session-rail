01Row anatomy

Three row types, one grammar borrowed from the reference panel.

The reference gives a project row (icon + bold name) and a two-line child row: status dot, name, pill badge, then a muted second line with a right-aligned action. That's kept verbatim for sessions. Subagents and tasks get a compressed single-line variant so depth stays readable at 300px.

goshift 3
goshift-d3 focused
master · opus 5 · 17:22
  1. Twisty — hidden when the node has no children, so leaf sessions don't reserve dead space.
  2. Status dot — green live, amber generating, grey idle, red exited. Breathes only while generating.
  3. Session name — Claude Code's own name field (goshift-d3), not a truncated UUID.
  4. Pill — the reference's primary slot. Here: focused for the session bound to the active editor, or exited.
  5. Detail line — branch · model · elapsed. Monospace, so columns of times line up down the rail.
  6. Action — focus terminal on a live session, open transcript on a dead one. One affordance per row, never two.
  7. Project action — a hover-only + at the right end of the project row starts a new session in that folder: a shell terminal rooted at the project directory with claude sent to it. Same one-affordance rule; the row itself still only toggles.

02Tree grammar

Four levels, each backed by a file already on disk.

Nothing here needs terminal scraping — Claude Code publishes all of it. Depth beyond one is real (spawnDepth: 2 occurs in the local history), and the subagents/ directory is flat, so parent links come from toolUseId matching, never from directory position.

LevelSourceKey fields
Project cwd, grouped basename of cwd; live session count
Session ~/.claude/sessions/<pid>.json name, sessionId, cwd, pid, procStart, entrypoint
Subagent projects/<enc-cwd>/<sessionId>/subagents/agent-*.meta.json agentType, description, spawnDepth, toolUseId
Task ~/.claude/tasks/<sessionId>/N.json subject, status, blockedBy

Parent resolution

parentOf(agent) =
  the transcript containing a record whose
  toolUseID === agent.meta.toolUseId

  search order:
    1. <sessionId>.jsonl          → agent is depth 1
    2. subagents/agent-*.jsonl    → agent nests under that agent

Verified on a real depth-2 agent: its toolUseId resolved into a sibling agent-*.jsonl, not the session transcript. The algorithm holds at any depth.

Liveness, honestly

  • Sessions — sessions/*.json outlives the process. Probe with process.kill(pid, 0) in a try/catch, and guard PID reuse with procStart.
  • Subagents — in-process, so no PID and no socket. A subagent is done when the tool_result for its toolUseId lands in the parent transcript, or when the SubagentStop hook fires. Without that signal every subagent shows busy forever.

05Build notes

What the first commit contains.

Contribution point

"contributes": {
  "viewsContainers": {
    "activitybar": [{
      "id": "sessionRail",
      "title": "Sessions",
      "icon": "media/rail.svg"

      "type": "tree"
    }]
  }
}

A single TreeDataProvider whose getChildren walks project → session → agent → task. Arbitrary nesting is native to the API; the pill and detail line map to TreeItem.description, the dot to a themed ThemeIcon, and the row action to contributes.menus["view/item/context"] with group: "inline".

Two halves, different stability

  • Hooks — events and liveness. SessionStart, SubagentStop, Stop POST to a localhost server the extension owns. Documented surface, push-based, no polling.
  • Filesystem — detail and backfill. Rich but private. Tail with byte offsets; never re-parse a multi-megabyte .jsonl on every change event or the extension host stalls.

This reads private state. Everything under ~/.claude is internal and unversioned, and drift is already visible in local history — 2.1.216 subagent records carry slug; 2.1.233 session records carry name, nameSource, nameSince. Version-gate the parsers and degrade to a flat session list when a shape is unrecognized.

Deferred past v1

  • Writing into a session over messagingSocketPath — undocumented IPC (peerProtocol: 1), easy way to disrupt a live run.
Draft one. Sample data is real local state: session names, branches, agent types (Explore, cavecrew-investigator) and the depth-2 nesting all come from ~/.claude on this machine.
